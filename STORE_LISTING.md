# Chrome Web Store listing

## Name

Neon Serpent

## Short description

Grow your neon serpent, chase the fruit, and beat your high score in a focused arcade game.

## Detailed description

Neon Serpent is a fast, polished Snake game designed for quick breaks and repeat runs. Guide the glowing serpent across the grid, collect fruit, grow longer, and chase a new high score.

Features:

- Smooth keyboard controls with arrow keys or WASD
- Touch controls for smaller screens
- Pause, resume, and restart controls
- Local best score saved on your device
- Responsive neon arcade interface
- No account, tracking, ads, or external permissions
