# Neon Serpent

Neon Serpent is a polished, self-contained Snake game that runs in the browser and as a Chrome extension popup.

## Play online

**[Open Neon Serpent on GitHub Pages](https://oussambencheikh.github.io/koora/)**

## Install locally in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this repository folder.

The extension has no external runtime dependencies, remote code, or permissions. All game logic and styling are included in the package.

## Publish to the Chrome Web Store

Create a ZIP containing `index.html`, `manifest.json`, and the four `icon-*.png` files, then upload it from the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole). Add store screenshots and the 128px icon when submitting the listing.
